# omp desktop

[English](README.md) | [简体中文](README.zh-CN.md)

omp desktop 是 AI coding agent——omp（oh-my-pi）的跨平台桌面客户端。它把 agent 装进一个原生窗口：与模型对话、看着它改文件跑命令，随时查看上下文、diff、子代理、终端与浏览器。agent 运行时内置于应用，无需单独安装 omp CLI。

外壳基于 **Tauri 2**（Rust 外壳 + Bun 宿主 + React 19 / Vite / Tailwind v4 前端）。

## 单进程，不是每会话一个

给 CLI 型 agent 套桌面壳的常见做法是每个会话起一个运行时子进程，走 RPC 通信。而 omp 运行时每份底座开销约 210MB，开九个会话就逼近 3GB——而且每个进程都是独立的故障域，单独崩溃。

omp desktop 把 omp SDK 作为库内嵌：单个 Bun 宿主进程用会话池持有全部会话，auth／模型／设置底座全进程共享一份。实测单进程跑 2 个会话总共 385MB。

内嵌 SDK 而非调用外部协议，是这个应用其余部分得以成立的前提：

- **运行时注入**。自定义工具通过 `createAgentSession({ customTools })` 以活函数形式注册，系统提示按会话追加。一个只能以序列化 RPC 载荷存在的工具做不到这件事。
- **共享热状态**。单进程持有所有打开会话的模型目录、MCP 连接、终端 PTY 与浏览器镜像——切会话时它们已经热了。
- **单一故障域**。代价，明说：宿主崩溃会带走所有会话。会话状态以 JSONL 落盘，重启后可恢复。

会话按工作目录以 JSONL 落盘，重启后重新加载。

## 上下文取证

多数客户端只给一个 token 数。omp desktop 给出每个 token 去了哪。

悬停上下文环，实时分解为：系统工具、MCP 工具（按 tools／prompt／device 拆分）、系统提示、记忆、技能、仓库规则，以及消息的压缩区／活跃区切分——另附**覆盖 21 家供应商的配额档位、重置倒计时与余额**，以及缓存保活统计（探针数、下次探针倒计时、花销、节省 token）。

输入框下方常驻统计条在流式期间 4Hz 刷新：缓存命中率与缓存失效次数、缓存读／写、输入输出 token、token 速度、成本（含子代理成本并做重复计数修正）、活跃时长、首字延迟、压缩次数。

## 功能

### 会话与对话

- 多会话并行管理：侧栏、项目分组、置顶、归档、行内改名
- **会话条目树**——完整对话记录以瀑布流形式呈现，每张卡片可独立抽屉展开，支持跳转导航、内容过滤与 fork 分支切换
- 消息队列：agent 工作时可继续排队追问、调整顺序，或中途 steer
- 流式 markdown：shiki 代码高亮、中文换行优化、Mermaid **与** Graphviz DOT/SVG 渲染、表格、任务列表，本地图片路径直接打开预览面板
- **四级噪声折叠**——长工具链折叠成「读了 29 个文件、跑了 14 条命令」，而不是 400 行原始记录
- 自研 diff 渲染器（零第三方 diff 依赖），4000 行上限，单遍分词保证跨行语法状态一致
- 中栏 **Git 管理**（项目行「更多」菜单）：全部分支/远程 ref 的提交图谱（含泳道拓扑），左侧分支树可切换历史范围，选中提交展示完整消息、逐文件增删行与父提交跳转
- Lexical 输入框：截图粘贴、文件拖入、`!` bash 模式（带 PATH 补全）、`@`／`/`／`$` 前缀补全、幽灵文本行内补全、历史召回、按住说话听写
- 图片灯箱，支持缩放与平移

### Agent 与委派

- 中栏 **Agent Hub**：子代理名册支持平铺与按父代理树两种视图、聚合用量、行内 steer 与停止、Enter 直接进入该子代理的独立标签页
- 子代理检查器：任务、当前活动、上下文量表、血缘、改动文件、输出与实时活动流
- 应用内编辑 agent 定义（新建、读取、保存子代理 markdown）
- 三档权限模式（always-ask／write／yolo）与按角色分配模型

### 工具面板（右栏）

八个可缩放、可拖拽重排的标签页，每个会话状态独立：

| 标签 | 能力 |
|---|---|
| **终端** | 真实宿主 PTY（Windows ConPTY／POSIX），每会话一个；关掉标签后进程继续运行 |
| **浏览器** | 手动沙箱浏览器，外加 agent 自有浏览器的 **CDP 实时画面镜像**——可以看它操作页面，也可以接管自己操作 |
| **Git diff** | 树状／平铺视图、按文件暂存／取消暂存／丢弃、带提交信息提交与推送、自研 diff 详情 |
| **文件** | 懒加载项目目录树、图片预览、行区间高亮，以及在编辑器／终端／文件管理器中打开 |
| **子代理** | 子代理卡片列表 + Hub 检查器 |
| **Agent Hub** | 同一检查器，从 Hub 卡片进入 |
| **后台命令** | 运行中的 bash／shell／eval 与宿主 job 快照；可展开，且在流式重绘中存活 |
| **侧边对话（`/btw`）** | 同一会话、同一模型上的旁路对话，不打扰主线 |

### 调度与自动化

- **定时任务**：结构化规则（minute／hourly／daily／weekly／monthly）或原始 5 段 cron，每次到点新建一个会话并绑定工作目录与模型；支持启停、立即运行、接下来三次触发预览、每任务运行历史
- agent 可通过 `create_automation` 工具为自己创建定时任务
- 调度器**先推进并落盘**下次运行槽位再派发，因此宿主崩溃不会重复触发

### 扩展能力

- **SSH 远程工作区**：通过 `ssh.json` 主机别名把远端目录挂载为本地桩工作区，含连通性探测与远端目录浏览
- **局域网远程控制**：在 `0.0.0.0:<port>` 上托管 UI，128 位访问密钥；远程客户端可观全部，写类 RPC 一律拒绝
- **电脑控制**：按会话开关，双 provider，物理显示器选择，外部浏览器路由
- **语音**：按住说话听写（本地 STT 模型可下载），以及系统语音朗读
- **本地统计仪表盘**：11 个板块，覆盖用量、模型、供应商、成本、请求、错误、调用链时间线、工具表现、挫败度分析与项目维度
- `/goal` 目标模式——token 预算制，支持暂停／继续／放弃，续跑无新工具进展时自动停止

### 配置

28 页设置中心，搜索可直接跳转并高亮任意配置项。都是真 CRUD，不是编辑 JSON：

- **模型与供应商**——OAuth 登录或 API key + base URL、逐模型启停与连通性测试、模型元数据编辑、多账号禁用／排序、套餐额度查询、自定义 OpenAI 兼容供应商向导、模型角色、快速切换环
- **MCP 服务器**——增删改，含传输方式、共享范围、env 与 headers、单服务器测试、日志查看器、一键全部重测
- **技能、hooks、agents、插件、扩展、记忆**——按作用域发现与启停、内容编辑、市场自动更新、跨四种后端的记忆文件浏览器
- **Shell**——图形化的有序首个匹配 bash 审批规则与拦截器规则，不是裸模式串列表
- **开发者**——自动 QA、GC 调参、低层压缩参数
- **高级**——按前缀分组展示其余全部底座配置
- 代理／no-proxy／自定义 CA 证书、终端字体选择器、按 profile 隔离

### 界面

- 六套主题（dark、light、midnight、warm-paper、deep-think、coral）或跟随系统，界面字体与字号，开关动效
- 消息轨刻度宽度随系统音频频谱变化
- 桌面通知与提示音、系统托盘（Windows／macOS 关窗隐藏到托盘）、单实例锁
- 应用内自动更新，含进度与重启
- 界面支持英文、简体中文、繁體中文
- 全局搜索面板（⌘⇧F），跨设置项与会话

## 安装

从 [Releases](https://github.com/a1398394385/oh-my-pi-desktop/releases/latest) 下载安装包。

**macOS（Apple Silicon）**——打开 `.dmg` 把应用拖进「应用程序」。安装包是 ad-hoc 签名，首次打开需要任选其一：

- 右键应用 →「打开」→「打开」，或
- 执行 `xattr -dr com.apple.quarantine /Applications/omp\ desktop.app`

**Windows（x64）**——运行 `-setup.exe`（NSIS 安装器）或 `.msi`。

更新走应用内推送；也可以在 设置 → 通用 →「检查更新」手动触发。

## 快速上手

1. 启动应用，打开 设置 → 模型 添加供应商——向导会带你走 OAuth 登录或「API key + base URL」配置。
2. 新建会话，选择项目目录和模型，开始对话。
3. agent 会读写文件、执行命令，并在对话里汇报结果；它做了什么，用右栏查看；上下文花了多少，悬停上下文环查看。

## 项目状态

**v0.3.0**（2026-10-23），跟进 omp **18.12.5**（当前上游最新版本）。

- **macOS**（Apple Silicon）与 **Windows**（x64）——构建未签名，见「安装」
- 暂未产出 Linux 安装包
- 暂未提供应用内插件安装，请用 `omp plugin install <package>`

版本跟进是刻意的设计选择：桌面端钉住已发布的 omp SDK 版本，而不是 vendor 一个 fork，因此上游的功能与修复不需要 rebase 就能到达桌面端。唯一的例外是携带了两个补丁——它们补的是 SDK 尚未暴露的两处行为：advisor 压缩开关的解耦，以及按池顺序选择凭据（桌面端提供账号排序功能，而 SDK 没有对应的重排 API）。
