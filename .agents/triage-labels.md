# Triage labels

| 技能角色 | 本仓库标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整,agent 可独立接手 |
| `ready-for-human` | `ready-for-human` | 需要人类处理 |
| `wontfix` | `wontfix` | 不会实施 |

`/to-tickets` 产出的 ticket 默认视为 `ready-for-agent`。
