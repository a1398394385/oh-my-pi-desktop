浏览器控制
当前版本无法实现ZCode 的内置浏览器壳（导入数据、清缓存、忽略证书）需要嵌入式浏览器面板。本应用没有该面板；omp 的 browser.* 只给 Agent 工具用 Puppeteer/CDP，不能对应这页产品功能。
电脑控制
对应 omp computer.enabled。ZCode 的 CUA helper 独立应用与输入框电脑操作按钮无法提供。
启用电脑控制允许 Agent 使用截图、输入、辅助功能等电脑控制工具。新会话后生效。
在输入框显示电脑操作按钮没有 CUA helper，输入区不会出现电脑操作入口。
记忆
工作区记忆后端写入 omp memory.backend。下方列出 profile 目录中的记忆文件。
工作区记忆关闭 / 本地总结管线。Hindsight、Mnemopi、Sharpshooter 需额外服务，这里不提供切换。

引导
omp 的 startup.setupWizard 是 TUI 向导。桌面端没有官方新手引导流程，下面是本应用的使用要点。
新建任务左侧「新建任务」或 ⌘N，在当前项目目录开一个新会话。
权限模式输入区左侧：变更前确认 / 自动编辑 / 完全访问，对应 omp tools.approvalMode。
模型与思考输入区右侧切换当前会话模型与推理强度。可启用的模型在「模型设置」里勾选。
