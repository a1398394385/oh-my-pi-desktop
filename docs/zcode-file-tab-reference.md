# ZCode「文件」标签页 UI 骨架与操作流程（参考规格）

> 调研日期：2026-10-21 · 调研对象：ZCode（`dev.zcode.app`，macOS，Electron）· 方法：computer use（AX 树 + 截图）实机操作
> 用途：作为 omp-desktop 右侧面板「文件」标签页改造的**对照规格**。本文只描述 ZCode 的事实与未验证项，不含本仓实现方案（方案另立）。
> 证据分级：**[实测]** 观察到的 UI 事实 · **[推断]** 由实测事实合理推导 · **[未验证]** 未能完成验证（附复验方法）

## 1. 术语

| 术语 | 含义 |
|---|---|
| 侧边面板（Side Pane） | 右侧可折叠面板，本文件描述其整体外壳 |
| 面板标签（Panel Tab） | 面板顶部的标签条，一个面板可开多个标签（如「文件」「终端」「浏览器」） |
| 文件标签 | 面板标签的一种，标题初始为「文件」，打开文件后变为该文件名 |
| 文件导航列 | 文件标签右侧的竖列：搜索框 + 根标题 + 文件树 |
| 内容区 | 文件标签左侧的阅读/源码区 |

## 2. 整体骨架

```
侧边面板
├── 标签条（Panel Tab Bar）                 ← 面板级，所有 tab 共用
│   ├── 搜索标签页（popover 按钮）
│   ├── 标签按钮「文件」/「AGENTS.md」…  [× 关闭]
│   ├── 新增标签（+）
│   ├── 进入完整视图（checkbox）
│   └── 收起侧边面板
└── 文件标签页体
    ├── 标题行：面包屑「workspace › .opencode › package.json」   [更多] [在 Finder 中打开] [收起文件导航]
    ├── 导航列（右）
    │   ├── 搜索框 [清空文件搜索]
    │   ├── 根标题「workspace」          [更多] [刷新文件树]
    │   └── 文件树（AXOutline，行高 31px）
    └── 内容区（左）：空态文案 / 预览 / 源码
```

两列之间有可拖拽分隔条，AX 角色 `AXSplitter`，accessible name「调整文件目录宽度」。**[实测]**

## 3. 标签条（面板级）

| 元素 | AX 角色 | 行为 | 证据 |
|---|---|---|---|
| 搜索标签页 | `AXPopUpButton` | 打开标签搜索/概览浮层（内容未展开验证） | [实测] 存在；[未验证] 浮层内容 |
| 标签按钮 | `AXButton`，name = `<标题> 关闭 <标题>` | 点击切换到该标签；内含子按钮「关闭」 | [实测] |
| 关闭 × | `AXButton (关闭 <标题>)` | 关闭该面板标签 | [实测] 存在 |
| 新增标签 | `AXButton (新增标签)` | 新建面板标签 | [实测] 存在；[未验证] 弹出的选择器内容 |
| 进入完整视图 | `AXCheckBox` | 面板进入全屏形态（复选态） | [实测] 存在；[未验证] 展开后的具体布局 |
| 收起侧边面板 | `AXButton` | 折叠整个侧边面板 | [实测] 存在；[未验证] 展开行为 |

标签标题随内容变化：空态时为「文件」，打开 `AGENTS.md` 后变为「AGENTS.md」，再打开 `package.json` 后变为「package.json`。**[实测]**

## 4. 文件导航列

### 4.1 搜索框

- `AXTextField`，accessible name「搜索文件」，占满导航列宽度。
- 输入即过滤；**过滤后列表从「目录树」切换为「扁平结果列表」**，两者不共存。**[实测]**
- 搜索激活时框内右侧出现「清空文件搜索」`AXButton`（help「清空文件搜索」）。**[实测]**
- 过滤结果的行标签是**完整相对路径**，用 ` / ` 分隔（例：`etower-forecast / etower-forecast / docs / 02a-api-integration-essentials-original.md`）；顶层文件只有一段（`AGENTS.md`）。**[实测]**
- 结果列表**目录与文件混排**（例：`els / build` 是目录，`network / idea uiDesigner.xml` 是文件）。**[实测]**
- 图标按类型区分：普通文件为橙色圆形 `{}`（JSON 类）、`package-lock.json` 等为锁形图标；md 文件为蓝色 md 图标。**[实测]**
- 匹配子串命中整段路径，`ui` 可命中 `uiDesigner.xml`、`mui` 等。**[推断]** 子串匹配，忽略大小写与否未验证。
- 结果行高 25–26px，比树模式行（31–32px）紧凑。**[实测]**

### 4.2 根标题行

- `AXHeading`，name = 工作区根目录名（本机为 `workspace`）。**[实测]**
- 行尾两个按钮：
  - `AXPopUpButton (更多)`（help「更多」）——**菜单内容未成功打开**，见 §8。**[实测存在 / 未验证内容]**
  - `AXButton (刷新文件树)`——重新拉取目录树；**行为未实测**。**[实测存在 / 未验证行为]**

### 4.3 文件树（无搜索词时）

- `AXOutline`，name = 根目录名；每个子项是 `AXRow`，行高 31–32px，**顶层只列一级目录**（`.agents` `.codex` `.idea` `.omc` `.opencode` `.playwright-mcp` `.sisyphus` `.vscode` `.zcode` `apache-maven-3.6.3` …）。**[实测]**
- 每行左侧有折叠箭头（▸）与文件夹图标，**目录为懒加载**：展开某目录后其子项以更高缩进插入。**[实测：箭头与懒加载结构存在；未实测点击展开]**
- 行内容为**目录名本身**（不是全路径），与搜索模式的「全路径」显示规则不同。**[实测]**
- 当前打开的文件所在行有高亮选中态。**[实测]**
- 树的排序：目录在前、大小写不敏感字典序（`.agents` … `.zcode` → `apache-maven-3.6.3` …）。**[实测]**

### 4.4 打开文件

- 合成**单击**未观察到打开效果；**双击**（`count=2`）成功打开并渲染。真实用户单击是否可打开**[未验证]**（合成点击期间存在用户真实鼠标干扰，`user_intervened` 多次出现）。
- 打开后：面板标签标题改为文件名；标题行面包屑变为 `workspace › .opencode › package.json`（多级，目录段用 `›` 分隔）。**[实测]**

## 5. 内容区

### 5.1 空态

- 居中一行文案「从目录中选择一个文件」，无插图、无按钮。**[实测]**
- 空态时「文件」按钮（面板「新标签页」页里的 `文件 / 从目录中选择一个文件` 卡片）是创建该文件标签的入口。**[实测]**

### 5.2 标题行

| 元素 | 行为 | 证据 |
|---|---|---|
| 面包屑 `workspace › … › file` | 显示当前位置；是否可点击跳转**[未验证]** | [实测] 文本 |
| 更多（`AXPopUpButton`） | 见 §5.3 | [实测] |
| 在 Finder 中打开（`AXButton`，help「在 Finder 中打开」） | 用系统文件管理器定位当前文件 | [实测] 存在 |
| 收起文件导航（`AXButton`，help「收起文件导航」） | 折叠右侧导航列，内容区全宽；**展开行为未实测** | [实测] 存在 |

### 5.3 「更多」菜单（内容区标题行）

打开 `AGENTS.md` 时实测菜单结构：

```
更多
├── 分组标题：Markdown
│   ├── 预览        ← 当前模式（md 默认预览）
│   └── 源码
├── ── 分隔线 ──
├── 复制绝对路径
└── 复制相对路径
```

- 菜单是独立 `AXMenu`（不是 web area 内 popover），菜单项 `AXMenuItem`，组标题为 `AXStaticText`。**[实测]**
- **分组标题随文件类型变化**：md → 「Markdown」；JSON 打开后未见预览/源码切换（直接源码视图），其菜单分组标题**[未验证]**。**[实测/未验证]**
- 「复制相对路径」相对工作区根目录。**[推断]**（同款菜单项在本仓同名实现中即为相对项目根）

### 5.4 渲染规则

| 文件类型 | 视图 | 证据 |
|---|---|---|
| Markdown | 默认**预览**（渲染标题/段落/列表/表格/代码块），可切**源码** | [实测] |
| JSON | 直接**源码**（行号 + 语法高亮） | [实测] |
| 代码块（md 预览内） | 围栏块，右上角：语言标签（`text`）+ 「自动换行」checkbox + 「复制代码」按钮 | [实测] |

- **源码视图**：左侧行号列 + 语法高亮（md 源码也按 md 语法着色），只读观感，未发现保存/编辑控件。**[实测]**
- 「自动换行」与「复制代码」是 `AXCheckBox` / `AXButton`，作用范围是该代码块。**[实测存在 / 行为未实测]**

## 6. 操作流程（实测路径）

1. 面板「新标签页」页 → 点「文件 / 从目录中选择一个文件」→ 打开文件标签（标题「文件」），右侧出现文件导航列，主体为空态文案。
2. 导航列搜索框输入关键字 → 列表由目录树切换为全路径扁平结果 → 双击某行 → 内容区渲染该文件，面包屑更新，面板标签标题变为文件名，文件树中该行高亮。
3. 内容区标题行「更多」→ 切「预览 / 源码」；「复制绝对路径 / 复制相对路径」写入剪贴板。
4. 关闭面板标签：点标签上的 ×。

## 7. 与 omp-desktop 现状对照

本仓对应实现：`ui-src/components/main/right/FilePage.tsx`（文件树 + 详情 + 面包屑 + 更多菜单）、`ui-src/components/main/right/RightPanel.tsx`（标签条：overview popover / 等宽可拖拽 tab / 新增按钮）。

| 能力 | ZCode | omp-desktop 现状 | 差距 |
|---|---|---|---|
| 面板标签条 | 搜索标签页 / tab / × / 新增 / 完整视图 / 收起面板 | overview popover / 等宽可拖拽 tab / 新增菜单 | 缺「进入完整视图」「收起侧边面板」显式入口 |
| 面板标签标题随内容变 | 是 | 否（固定为 tab 名） | 需支持标题跟随文件名 |
| 文件导航列位置 | 右侧竖列 + 可拖拽分隔条 | 同 | 一致 |
| 搜索框 | 有，实时过滤，树↔扁平列表切换 | 无 | **缺文件搜索** |
| 搜索结果显示 | 全路径 ` / ` 分隔，目录/文件混排 | — | 需新实现 |
| 树显示 | 顶层目录 + 懒加载展开 + 折叠箭头 | 逐级懒加载展开 | 基本一致 |
| 根标题行 | 根名 + 更多 + 刷新 | 无 | **缺「刷新文件树」** |
| 内容区空态 | 纯文案 | 树即空态 | 形态不同（保留现状更省） |
| Markdown | 预览 / 源码双模式 | 仅文本 + 行号 | **缺预览模式** |
| 代码块工具 | 语言标签 / 自动换行 / 复制代码 | 无 | **缺** |
| 非文本文件 | 未验证图片渲染 | 图片走 `read_image` 预览 | 现状更强 |
| 「在 Finder 中打开」 | 标题行独立按钮 | 收在「更多」菜单里（打开方式菜单） | 可对齐为独立按钮 |
| 路径复制 | 更多菜单内两项 | 更多菜单内已有 | 一致 |

## 8. 未验证项（需复验）

复验前提：用户不要同时操作 ZCode 窗口（本次多次出现 `user_intervened`，合成点击与真实鼠标互相干扰）。

1. 文件树根标题行「更多」菜单的具体项 —— 坐标点击未能弹出，需用 AX index 精确点击。
2. 目录行单击/双击语义：展开目录？打开目录？是否与文件行不同。
3. 「刷新文件树」点击后的行为（是否保留展开状态与当前选中项）。
4. 「收起文件导航」/「进入完整视图」/「收起侧边面板」的实际布局变化。
5. 「搜索标签页」浮层内容、「新增标签」选择器内容。
6. 非 Markdown 文件的「更多」菜单分组（JSON 无预览/源码时的菜单形态）。
7. 图片、PDF 等二进制文件在内容区的渲染。
8. 单击是否即可打开文件（本次仅双击成功）。
9. 面包屑各段是否可点击跳转。
10. 代码块「自动换行」切换后的换行效果；搜索大小写敏感性；无结果时的空态文案。
